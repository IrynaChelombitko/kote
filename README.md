# Kote

Clickable prototype of Kote, a concept booking platform for small guided groups on hard routes in the far North.

Live: https://irynachelombitko.github.io/kote/

Concept, product and visual design by Iryna Chelombitko. Not a real company: nothing is booked or charged. Photography generated with Gemini.

Pages: deployed from the main branch, root folder.
